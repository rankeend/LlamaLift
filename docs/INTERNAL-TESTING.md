# v0.4 内测清单

## 安装与启动

- [ ] Windows 10 x64 可以启动。
- [ ] Windows 11 x64 可以启动。
- [ ] 安装版能够安装、启动和卸载。
- [ ] 便携版配置保存在程序目录的 `data/`。
- [ ] 新安装版配置保存在 `%LOCALAPPDATA%\LlamaLift`；旧内测目录存在时继续读取旧目录。

## llama.cpp 后端

- [ ] 新机器无需预装 llama.cpp，即可刷新官方 Windows x64 版本列表。
- [ ] 硬件检测能正确显示 CPU、系统内存、GPU、显存和推荐后端。
- [ ] 可以安装最新 CPU 构建，安装后自动绑定 `llama-server.exe`。
- [ ] NVIDIA 机器能安装 CUDA 构建及配套 cudart DLL。
- [ ] AMD/Intel 机器能获得合理的 Vulkan、HIP 或 SYCL 推荐。
- [ ] 可同时保留两个版本，并在不同模型配置间切换。
- [ ] GitHub 断网或超时时会有限重试，且不会破坏已有运行时。
- [ ] 摘要不匹配或 ZIP 越界路径会终止安装。
- [ ] 仍可手工选择并检测 `llama-server.exe`。
- [ ] CUDA 构建可以启动。
- [ ] Vulkan 或 CPU 构建可以启动。
- [ ] 纯文本 GGUF 可以运行。
- [ ] 带 mmproj 的多模态模型可以运行。
- [ ] 模型路径包含空格时仍可启动。

## API 与网络

- [ ] `127.0.0.1` 本机访问正常。
- [ ] `/v1/chat/completions` 测试正常。
- [ ] 后端支持时 `/v1/responses` 测试正常。
- [ ] `0.0.0.0` 模式会显示安全提醒。
- [ ] API Key 文件可以正确传给 llama-server。
- [ ] API Key 管理器可创建、生成、导入、脱敏显示、选择和删除托管密钥。
- [ ] 托管 Key 未点击“显示”时不出现明文，日志中也不包含 Key 内容。
- [ ] 端口被占用时能够识别并提示。

## 自定义命令预检

- [ ] 无效端口、无效 GPU 层、未闭合引号和 ubatch 大于 batch 时会给出修改建议。
- [ ] 超大上下文、未知参数、端口占用和局域网无 API Key 时会给出风险提醒。
- [ ] 选择“返回修改”时不保存；选择“仍然保存”时保留完整原始命令，并在启动时按原文执行。

## 参数自适应

- [ ] GGUF v2/v3 能识别模型名称、架构、上下文、层数、嵌入维度和量化。
- [ ] 快速档优先选择较小上下文和 Q4 KV Cache。
- [ ] 均衡档根据内存/显存给出稳定的上下文和 Q8 KV Cache。
- [ ] 极限档在空间允许时使用更长上下文和高精度 KV Cache，空间不足时会降级并解释原因。
- [ ] 纯 CPU 机器不会生成 GPU 全层卸载设置。
- [ ] 显存足够时可以选择 `all`，不足时使用 llama.cpp 的 `auto + fit`。
- [ ] 当前 GGUF 权重量化与推荐量化被明确区分，不会暗示运行参数能改变量化文件。
- [ ] 方案应用后，上下文、GPU 层、KV Cache、线程、batch 和 ubatch 均可手工覆盖。
- [ ] 分片模型使用首个 GGUF 时不会长时间扫描或读取张量内容。

## 界面与稳定性

- [ ] 浅色、深色和系统主题正常。
- [ ] 940×600 与 1320×840 窗口下无文字、输入框、按钮或圆角裁切。
- [ ] 100%、125%、150%、175%、200% 缩放下无明显遮挡或横向滚动条。
- [ ] 六个页面顶部和底部状态正常，侧栏导航左右圆角完整。
- [ ] 键盘 Tab 顺序与页面视觉顺序一致，焦点状态清晰可见。
- [ ] 日志使用 INFO/WARN/ERROR 文本级别，状态不只依赖颜色。
- [ ] 多配置的新建、复制、保存和删除正常。
- [ ] 托盘隐藏、恢复和退出正常。
- [ ] 配置损坏后能够备份并恢复默认配置。
- [ ] 日志不会包含 API Key 内容。

反馈请附上 Windows 版本、llama.cpp 构建版本、GPU/CPU、复现步骤和已脱敏日志。
