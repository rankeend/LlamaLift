# v0.1 内测清单

## 安装与启动

- [ ] Windows 10 x64 可以启动。
- [ ] Windows 11 x64 可以启动。
- [ ] 安装版能够安装、启动和卸载。
- [ ] 便携版配置保存在程序目录的 `data/`。
- [ ] 安装版配置保存在 `%LOCALAPPDATA%\LlamaServerManager`。

## llama.cpp 后端

- [ ] 可以选择并检测 `llama-server.exe`。
- [ ] CUDA 构建可以启动。
- [ ] Vulkan 或 CPU 构建可以启动。
- [ ] 纯文本 GGUF 可以运行。
- [ ] 带 mmproj 的多模态模型可以运行。
- [ ] 模型路径包含空格时仍可启动。

## API 与网络

- [ ] `127.0.0.1` 本机访问正常。
- [ ] `/v1/chat/completions` 测试正常。
- [ ] 后端支持时 `/v1/responses` 测试正常。
- [ ] `0.0.0.0` 模式会显示安全提醒。
- [ ] API Key 文件可以正确传给 llama-server。
- [ ] 端口被占用时能够识别并提示。

## 界面与稳定性

- [ ] 浅色、深色和系统主题正常。
- [ ] 100%、125%、150% 缩放下无明显遮挡。
- [ ] 多配置的新建、复制、保存和删除正常。
- [ ] 托盘隐藏、恢复和退出正常。
- [ ] 配置损坏后能够备份并恢复默认配置。
- [ ] 日志不会包含 API Key 内容。

反馈请附上 Windows 版本、llama.cpp 构建版本、GPU/CPU、复现步骤和已脱敏日志。
