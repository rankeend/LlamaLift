# LlamaLift v0.4.0-dev

> 本地模型，一键起飞。

这是 LlamaLift 的私有 v0.4 内测版本。本版本重点提升参数同步准确性、llama-server 生命周期可靠性、API Key 路径兼容、运行时自动定位、监测开销和高 DPI 界面稳定性。

## 主要更新

- 三档参数、简易表单、命令预览和实际启动参数保持一致；TurboQuant KV 类型严格按运行时能力选择。
- 服务启停、重启、长时间模型加载、端口释放和异常退出使用统一异步生命周期管理。
- 自动检测本机 llama-server 安装位置，确认后填入；未找到时继续支持手动目录或 EXE 选择。
- API Key 启动前执行真实可读性检查，并自动兼容 Ollama 等构建无法读取中文参数路径的问题。
- 优化 GPU 监测与日志刷新，降低空闲和高日志吞吐时的界面开销。
- 修复圆角底尖角、按钮换行和多处最小窗口/高 DPI 布局问题。

## 验证

- 90 项离线功能与故障回归测试通过。
- 22 个 UI 场景通过，覆盖 940×600、1320×840、浅色/深色及 125%/150%/175%/200% DPI。
- 便携版和 Inno Setup 安装版构建通过。
