# v1.0 Preview 内测清单

## 协议接入

- [ ] Responses 使用 `/v1/responses`、`/v1` Base URL 和 Bearer 鉴权。
- [ ] Chat Completions 使用 `/v1/chat/completions`、`/v1` Base URL 和 Bearer 鉴权。
- [ ] Anthropic Messages 使用 `/v1/messages`、主机根 Base URL 和 `x-api-key` 鉴权。
- [ ] 切换协议后端点说明立即同步，但启动命令和未知参数不改变。
- [ ] “测试当前”只请求所选协议；“测试全部”分别给出三项结果。
- [ ] 旧配置升级后默认选择 Responses，模型、端口、API Key 和自定义参数不丢失。

## 状态与生命周期

- [ ] 未启动时侧栏显示“llama.cpp · 已关闭”，不再显示安装/便携模式。
- [ ] 大模型加载期间显示“正在加载”，不会因固定超时被自动终止。
- [ ] `/health` 就绪后显示“已就绪”；存在处理请求时显示“输出中”。
- [ ] 停止、端口占用、外部服务和异常退出都有独立状态，且不只依赖颜色。
- [ ] 连续启动/停止/重启 20 轮后无孤儿进程、残留端口或错误状态回跳。

## 真人流程

- [ ] 空白 Windows 10/11 机器安装后能发现或下载安装 llama.cpp。
- [ ] 自动发现 llama-server 结果可确认；识别失败可选择目录或 EXE。
- [ ] 新建模型、选择 GGUF、自适应调参、保存、启动、协议测试、监测、停止全流程无阻断。
- [ ] 自定义命令、未知参数、三个预设和 API Key 在保存、切换页面和重启应用后保持一致。
- [ ] 新生成 Key 满足 `sk-llamalift-` 加 64 位小写十六进制，日志不泄露明文。

## 界面与发布

- [ ] 940×600、1320×840 和 125%/150%/175%/200% DPI 无裁切、横向滚动或底尖角。
- [ ] 浅色、深色、跟随系统下焦点、禁用、警告和错误状态清楚。
- [ ] 便携版、安装版、卸载、旧配置迁移、ZIP 内容和 SHA-256 均验证。

反馈请附 Windows 版本、llama.cpp commit/构建类型、硬件、所选协议、复现步骤和脱敏日志。
